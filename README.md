# 🌐 My Portfolio

This is my personal portfolio website showcasing my **skills**, **projects**, and **contact information**.  
Built with **React**, **Bootstrap**, **Framer Motion**, and modern UI design principles.

## ✨ Features
- 🎨 Clean and modern UI with blue & white theme
- 📱 Fully responsive design
- 🎥 Smooth animations with Framer Motion
- 🖼 Projects showcased in carousel/grid format
- 📬 Contact form & social links

## 🛠 Tech Stack
- **Frontend:** React, Bootstrap
- **Animations:** Framer Motion, AOS
- **Styling:** CSS, Bootstrap
- **Deployment:** GitHub Pages / Netlify / Vercel

## 📂 Sections
- **Home** – Intro banner with call-to-action
- **About Me** – My journey & skills
- **Skills** – Key technical skills
- **Projects** – Portfolio work showcase
- **Contact** – Contact form & links
- **Footer** – Quick links & copyright

## 🚀 How to Run Locally
```bash
git clone https://github.com/<your-username>/my-portfolio.git
cd my-portfolio
